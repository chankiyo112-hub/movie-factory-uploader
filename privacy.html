プライバシーポリシー

最終更新日：2026年10月4日

movie-factory-uploader（以下「本ツール」）は、運営者が自分の YouTube チャンネルに自分の動画をアップロードするための個人用ツールです。本ツールは YouTube API サービスを使用しています。本ツールを使うことで、YouTube 利用規約に同意したものとみなされます。Google によるデータの扱いは Google プライバシーポリシーをご覧ください。

1. 取得する情報

運営者が Google アカウントで許可した場合に限り、YouTube Data API を通じて次の情報を扱います。

  • 運営者のチャンネルの名前と ID
  • 運営者のチャンネルに公開済みの動画のタイトル・説明文・タグ・サムネイル・公開日
  • 許可のトークン（アップロードのために Google が発行する認証情報）

2. 使い方

取得した情報は、運営者自身のチャンネルへの動画のアップロード、サムネイルの設定、新しい動画のタイトルと説明文を作る際の参考にだけ使います。広告、分析目的の販売、第三者への提供には使いません。

3. 保存と共有

許可のトークンと取得した情報は、運営者のパソコンの中にだけ保存します。外部のサーバーに送ったり、第三者に共有・販売したりすることはありません。

4. 削除と許可の取り消し

運営者のパソコンからトークンと保存した情報を消すことで、いつでも削除できます。また、Google アカウントのセキュリティ設定から、本ツールへの許可をいつでも取り消せます。

5. お問い合わせ

GitHub の Issues からお問い合わせください。
